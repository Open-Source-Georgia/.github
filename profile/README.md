# Open Source Georgia 🇬🇪

**Learn together. Build together.**

A friendly community for people in Georgia to learn, use, and contribute to open source. Beginners are very welcome.

</div>

## Steps to get started

1. **Join this GitHub organization** by opening an [issue](LINK_TO_SUPPORT_REPO_ISSUE_FORM) (you will receive an invitation).
2. **Join our Discord server** to chat and ask questions: [DISCORD_LINK](DISCORD_LINK)
3. **New to GitHub?** Learn the basics with [GitHub Skills](https://skills.github.com).
4. **Practice the workflow** by making a first pull request in [first-contributions](https://github.com/firstcontributions/first-contributions).
5. **Make your membership public** so people can see you are part of Open Source Georgia (instructions are in our support repo).
6. **Share what you're working on** in the server. Questions and half-finished ideas are welcome.
